# 五大联赛预测方案（Prediction Method v3.0）

> 适用：欧洲冠军联赛 + 英超 + 西甲 + 德甲
> 模型：Elo 评级 + 联赛参数化泊松分布 + 统计期望 + 市场维度 + **价值投注分析**
> 更新：`python scripts/auto_update.py`（每日拉取 football-data.org 赛程 + 竞彩赔率后自动重算）

---

## 1. 模型架构总览

```
数据层                          模型层                         输出层
┌──────────────┐   ┌─────────────────────┐   ┌──────────────────────┐
│ Elo 评级      │ → │ Elo 期望(30%)       │ → │ 胜平负概率            │
│ 场均进球/失球 │   │ 泊松矩阵(70%)       │ → │ xG / 最可能比分        │
│ 联赛参数      │   │ 联赛主场优势/平局下限│ → │ 总进球分布 0~6+        │
│ 积分榜(校准)  │   └──────┬──────────────┘ → │ 统计期望(射门/角球等)  │
│ 竞彩赔率(去水)│           ↓                │ 市场维度(大小球/BTTS)  │
└──────────────┘   ┌─────────────────────┐   └──────────────────────┘
                   │ 赔率反推 Elo 校准     │   ┌──────────────────────┐
                   │ 价值投注分析(edge/Kelly)│→│ edge/Kelly/EV/信号/建议│
                   └─────────────────────┘   └──────────────────────┘
```

**一句话规则**：主队胜率 = 30% × Elo 期望（主场 +60）+ 70% × 泊松胜率；再以竞彩赔率去水概率为市场基准，计算 edge 与 Kelly，输出价值信号。

## 3. 核心模型

### 3.1 联赛参数化 xG

```
攻击系数 attack  = 球队场均进球 / 联赛场均进球
防守系数 defense = 球队场均失球 / 联赛场均进球

xG(主) = (联赛场均 + 主场优势) × attack(主) × defense(客)
xG(客) = 联赛场均 × attack(客) × defense(主)
```

- 各联赛场均进球（每队）：英超 1.50 / 西甲 1.35 / 意甲 1.40 / 德甲 1.60 / 法甲 1.45
- 主场优势：英超 0.30 / 西甲 0.28 / 意甲 0.30 / 德甲 0.25 / 法甲 0.25

### 3.2 泊松比分矩阵

对每对 (主进球 g1, 客进球 g2)，g ∈ [0,8]：

```
P(g1,g2) = Poisson(g1; xG主) × Poisson(g2; xG客)
```

聚合得到：
- **胜平负概率**（泊松部分）
- **最可能比分** TOP4
- **总进球分布**（0/1/2/3/4/5/6+ 概率）

### 3.3 胜平负合成

```
综合(主) = 30% × Elo期望(主) + 70% × 泊松胜率(主)
综合(平) = 70% × 泊松平率 + 平局下限 × (1 − |Elo期望−0.5|)
综合(客) = 30% × (1−Elo期望(主)) + 70% × 泊松胜率(客)
归一化 → 最终概率；修正因子(伤病/轮换)以概率点直接叠加
```

- **Elo 期望**：`1 / (1 + 10^((Elo客 − Elo主−60)/400))`，主队 +60
- **平局下限**：英超/西甲/法甲 0.15，意甲 0.16，德甲 0.14
- **确定性** = 最大概率 − 次大概率；≥20% 高 / ≥10% 中 / <10% 低

## 4. 统计期望模型（各项数据期望）

> 原理：所有统计量由"攻防系数 × 联赛基准"驱动，强队射门多、控球高、角球多、黄牌少。

| 统计量 | 公式 | 约束 |
|--------|------|------|
| 射门(主) | `联赛基准射门 × (0.85+0.15×attack主) × (1.05−0.10×defense客) × (1+主场优势×0.2)` | 6~24 |
| 射正 | `射门 × 0.36`（射正率 36%） | — |
| 角球 | `联赛基准角球 × (0.7+0.3×attack) × (1+(1−defense)×0.12)` | 2.5~9.0 |
| 黄牌 | `联赛基准黄牌 × (1.15 − attack×0.12)` | 1.2~3.5 |
| 控球率 | `50 + (Elo主 − Elo客)/30 + 2`（主场微调） | 35~65 |

联赛基准（每队场均）：射门 12.7~14.3 / 角球 5.0~5.8 / 黄牌 1.7~2.4（见 leagues.json）

## 5. 市场维度（衍生概率）

| 维度 | 算法 | 说明 |
|------|------|------|
| 大小球 2.5 | 总进球分布聚合 `P(总进球>2.5)` | 1.5 / 3.5 同理 |
| 双方进球 BTTS | `(1−e^(−xG主)) × (1−e^(−xG客))` | 泊松零进球假设 |
| 双胜彩 | 1X = 主胜+平 / X2 = 平+客胜 / 12 = 主胜+客胜 | 概率直接相加 |
| 让球盘 主−1 | 净胜球分布：赢盘=净胜≥2 / 走水=净胜=1 / 输盘=净胜≤0 | 客+1 对称 |

## 8. 价值投注模型（v3.0 新增）

> 目标：计算**模型期望概率**与**市场赔率隐含概率**的差值（edge），结合期望值（EV）寻找价值机会。

### 8.1 赔率数据源：中国体彩竞彩（免费，官方）

- 接口：`webapi.sporttery.cn/gateway/jc/football/getMatchCalculatorV1.qry?poolCode=had,hhad`
- 字段：`had`（胜平负赔率 h/d/a）、`hhad`（让球胜平负，含让球数 goalLine）、`crs`（比分赔率）
- 覆盖：竞彩在售全部赛事（欧冠/英超/西甲/德甲按联赛筛选），实时更新
- 队名映射：竞彩中文简称/英文码 → 系统名（`scripts/fetch_odds.py` 内置 JC_ALIAS/JC_CODE）

### 8.2 市场去水（去抽水）

```
隐含概率 i = 1/赔率；总和 S = Σi；去水概率 = i/S
抽水率 vig = S − 1（竞彩约 12~13%，即返还率约 87~88%）
```

### 8.3 Edge 与期望值

```
Edge_k = 模型概率_k − 市场去水概率_k   （百分点）
EV_k   = 模型概率_k × 赔率_k − 1        （期望收益率，%）
```

### 8.4 半 Kelly 仓位

```
f_k = (p_k × odds_k − 1) / (odds_k − 1)，半 Kelly = f × 50%
Kelly > 0 ⟺ EV > 0（正期望，价值投注的充分条件）
```

### 8.5 信号分级（一句话可判定）

| 信号 | 条件 | 含义 |
|------|------|------|
| STRONG 强价值 | edge ≥ 5% 且 Kelly>0 | 模型显著高于市场且正期望 |
| VALUE 价值 | edge ≥ 3% 且 Kelly>0 | 有正期望价值 |
| WATCH 观察 | edge ≥ 3% 但 Kelly=0 | 模型高于市场但赔率不足正期望 |
| NONE 无 | 其他 | 无价值机会 |

### 8.6 赔率反推 Elo 校准（关键前处理）

为避免新队（Elo 默认 1500）制造虚假 edge，用市场赔率反推其实力：

```
归一化主队胜率 ph = p_home/(p_home+p_away)（去水后）
Elo 差 = 400 × log10(ph/(1−ph)) − 主场加成
已知一方 Elo → 解另一方；双方未知 → 围绕 1500 对称拉开；迭代 3 轮传播
```

执行：`python scripts/update_elo_from_odds.py --rounds 3`（每日任务自动执行）

## 9. 校准与验证

1. **每日校准**：football-data.org 积分榜（排名→Elo）+ 竞彩赔率反推（update_elo_from_odds.py，迭代 3 轮）
2. **赛后验证**（建议固化流程）：
   - 方向命中率：预测主胜且主队胜 = 命中
   - 比分命中率：最可能比分与实际比分
   - xG 校准：实际进球 vs xG 期望的偏差（xG 模型系统性偏差时调 `XG_PER_SHOT`/攻防系数）
   - **价值模型回测**：记录 edge≥3% 且 Kelly>0 的信号，赛后统计实际命中率 vs 模型概率（校准 logit 缩放）
3. **阈值规则**：确定性 ≥30% 且方向概率 ≥60% 才输出"强信号"标注
4. **零值标记**：任何指标为 0 必须显式展示（如某队预期角球 0）
5. **价值信号校准**：连续 N 场 STRONG 信号若命中率 < 模型概率−10%，下调 edge 阈值或调优 Elo

## 10. 局限与风险

- **泊松假设**：进球相互独立，未建模赛程密度、伤病、裁判、天气
- **Elo 滞后**：赛季初升班马/换帅球队 Elo 校准滞后
- **统计期望粗糙**：射门/角球等为系数驱动的一阶估计，非逐事件模型；黄牌个体差异大
- **免费层限制**：football-data.org 免费层 10 次/分钟、比分延迟、无球员级数据
- **竞彩赔率口径**：竞彩返还率约 87-88%（抽水高），edge 天然偏保守；且竞彩非全天候开盘，周末场次覆盖全、周中少
- **价值≠必胜**：edge 是统计优势，仍需样本验证；单场 Kelly 仓位建议 ≤ 半 Kelly 的 1/2
- **不构成投注建议**：模型输出仅反映统计倾向，足球强随机性——即使 70% 概率也有 3 成变数
